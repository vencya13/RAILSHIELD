RAILSHIELD — Predictive Counterfactual Railway Control

RAILSHIELD is an AI-powered railway traffic management and decision-support system that predicts potential train conflicts, analyzes delay propagation, identifies root causes, and evaluates possible interventions before they are applied.

Key Features
Railway traffic simulation
Train conflict detection
Headway and delay analysis
Delay propagation prediction
Root-cause analysis
Counterfactual intervention simulation
Decision-support recommendations
FastAPI backend
Interactive web dashboard
Technology Stack

Backend: Python, FastAPI
Simulation: Custom railway simulation engine
Frontend: HTML, CSS, JavaScript

Current Status

Version: Prototype

The current system uses simulated railway scenarios and rule-based railway analysis.

Future Development

A machine learning layer using synthetic railway scenarios and Random Forest is planned for predictive conflict-risk analysis. Future versions may also integrate real railway operational data for validation and real-time decision support.

Disclaimer

RAILSHIELD is a research and hackathon prototype. It is not intended to directly control railway infrastructure or replace certified railway signalling and safety systems.
